# Contributing

This is primarily a portfolio/academic project, but improvements are welcome.

## Development flow

1. Create a branch for your change.
2. Keep changes focused and readable.
3. Update documentation when behavior or setup changes.
4. Run the available backend/frontend checks locally.
5. Open a pull request with a clear summary and testing notes.

## Commit style

Prefer focused commits such as:

- `feat: add authenticated registration`
- `fix: handle prediction API error`
- `docs: improve project setup`
- `chore: add CI workflow`
