# Security Policy

## Scope

This repository is a portfolio/academic implementation. Please do not submit real personal, financial, banking, API-key, token or credential data as issues or pull requests.

## Reporting a vulnerability

For a security issue, contact the repository owner privately through the GitHub profile associated with this repository.

Do not publish credentials, secrets or sensitive personal data in a public issue.

## Local security rules

- Keep `.env` files out of Git.
- Use `.env.example` files with placeholders only.
- Rotate any credential that is accidentally exposed.
- Do not commit database passwords, JWT secrets, API keys or service-account files.
